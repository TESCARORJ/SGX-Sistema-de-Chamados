# Checklist de Homologacao - Base de Conhecimento

## Objetivo

Validar funcionalmente o fechamento da Base de Conhecimento (Sprints 1 a 6), cobrindo administracao de artigos, consulta no portal, integracao com chamados, historico e auditoria.

## Cenarios de homologacao

### Fluxo administrativo de artigos

- [ ] Administrador cria artigo.
- [ ] Administrador edita artigo.
- [ ] Administrador publica artigo.
- [ ] Administrador arquiva artigo.
- [ ] Administrador reativa artigo.
- [ ] Busca administrativa funciona por status.
- [ ] Busca administrativa funciona por visibilidade.
- [ ] Auditoria registra acoes administrativas.

### Fluxo de consulta no portal e visibilidade

- [ ] Solicitante visualiza artigo publicado no portal.
- [ ] Solicitante nao visualiza artigo interno de atendente/admin.
- [ ] Atendente visualiza artigo permitido.
- [ ] Administrador visualiza artigo administrativo.
- [ ] Busca no portal funciona por titulo.
- [ ] Busca no portal funciona por tags.

### Fluxo de vinculo com chamado

- [ ] Artigo publicado pode ser vinculado ao chamado.
- [ ] Artigo arquivado nao pode ser vinculado.
- [ ] Artigo inativo nao pode ser vinculado.
- [ ] Vinculo duplicado e bloqueado.
- [ ] Artigo vinculado aparece no detalhe do chamado.
- [ ] Remocao do vinculo funciona.
- [ ] Historico do chamado registra vinculo.
- [ ] Historico do chamado registra remocao.

## Evidencias obrigatorias

- [ ] Print da listagem administrativa da Base de Conhecimento.
- [ ] Print do formulario de criacao/edicao de artigo.
- [ ] Print da acao de publicar/arquivar/reativar.
- [ ] Print da listagem do portal.
- [ ] Print do detalhe do artigo no portal por slug.
- [ ] Print da secao "Base de conhecimento" no detalhe administrativo do chamado.
- [ ] Print do fluxo de vinculo e remocao de vinculo.
- [ ] Print do historico do chamado com eventos de vinculo/remocao.
- [ ] Print do registro de auditoria das acoes administrativas.
