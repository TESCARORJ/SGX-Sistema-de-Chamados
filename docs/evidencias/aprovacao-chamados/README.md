# Evidencias - Aprovacao de Chamados

Objetivo:
Registrar evidencias reais da homologacao institucional do modulo Aprovacao de Chamados.

Instrucoes:
- Nao usar prints ficticios.
- Nao inventar resultados.
- Preencher um bloco por cenario validado.

## Cenarios sugeridos para coleta de evidencias
- Fluxo administrativo de solicitacao manual.
- Aprovacao de chamado pendente.
- Reprovacao com justificativa obrigatoria.
- Cancelamento com justificativa obrigatoria.
- Abertura por catalogo com aprovacao automatica.
- Bloqueio operacional de chamado pendente/reprovado.
- Acompanhamento no portal do solicitante.
- Restricao de acesso para chamado de outro solicitante.
