# Evidencias de Homologacao - Catalogo de Servicos

Este diretorio foi preparado para armazenamento de evidencias reais da homologacao funcional do modulo Catalogo de Servicos.

Importante:
- Nao inserir evidencias ficticias.
- Nao inserir prints gerados artificialmente.
- Registrar apenas execucoes reais com usuario, ambiente e data.

## Template de registro por cenario

### Cenario
Descreva o cenario validado.

### Perfil utilizado
Informe o perfil utilizado no teste (Administrador, Atendente, Solicitante, etc).

### Dados usados no teste
Liste dados de entrada e entidades usadas (servico, departamento, categoria, usuario, etc).

### Resultado esperado
Descreva o comportamento esperado.

### Resultado obtido
Descreva o resultado efetivamente observado.

### Status
Informe: Validado, Reprovado ou Bloqueado.

### Evidencia/print
Anexe caminho do arquivo de evidencia (print, video, export, log autorizado, etc).

### Observacoes
Registre observacoes adicionais, riscos, inconsistencias ou dependencias.

### Data da validacao
Informe a data da execucao.

### Responsavel pela validacao
Informe nome e area do responsavel.
