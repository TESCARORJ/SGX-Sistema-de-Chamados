## Sugestao de uso

1. Duplicar o bloco "Modelo de registro por cenario" para cada validacao.
2. Vincular cada evidência ao item correspondente do checklist de homologacao.
3. Armazenar prints reais no mesmo diretorio, com nome padrao.

### Padrao sugerido para nome de arquivo

- `YYYY-MM-DD-cenario-perfil-tela.png`
